# M/S SARKER - Website

You can now open the website directly in any browser.

## How to Run the Project

Simply double-click `index.html` in your file explorer to open it in your browser. Since the project uses a bundled script, it no longer requires a local web server to bypass CORS restrictions.

## Project Structure
- `index.html`: Main entry point.
- `data/company-data.js`: Central data store for the website.
- `services/`: Core logic (Routing, CSRF).
- `components/`: UI components (Navbar, Home, Pages).
- `admin/`: Admin panel logic.
